# KarjMitra HTML/CSS/JS Edition

Open `index.html` for the public dashboard and `login.html` for the admin demo.

Demo login: `admin` / `admin123`

Features: public dashboard, dashboard statistics, payments, installments, contacts, add/delete actions, overpayment validation, localStorage persistence, JSON import/export, responsive layout, transitions and animations.

## Netlify
Upload the extracted folder. No build command. Publish directory: project root.

## GitHub Pages
Push all files to the repository root and enable Pages from the main branch root.

## Warning
This static edition has no secure server authentication or shared database. Do not store private financial data. Each browser has separate localStorage data.
